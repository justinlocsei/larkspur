# Security Policy

## Supported Versions

Security fixes are provided for the latest release only.

## Reporting a Vulnerability

Please report security issues privately rather than opening a public GitHub issue.

Use GitHub's [private vulnerability reporting form](https://github.com/justinlocsei/larkspur/security/advisories/new) or the **Report a vulnerability** button on the repository's [Security Advisories](https://github.com/justinlocsei/larkspur/security/advisories) page. Include as much detail as you can about the issue, steps to reproduce it, and any impact you have identified. I will acknowledge receipt as soon as possible and follow up when I have more information or a fix.

## Security Advisories

Published advisories are listed on the [Security Advisories](https://github.com/justinlocsei/larkspur/security/advisories) page.
