# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] (2026-09-19)

### Changes

- Show a combined list of validation errors ([#24])
- Improve error messages for flag conflicts with middleware ([#23])
- Support middleware commands ([#20])
- Support a version flag ([#18])

### Development

- Upgrade to Vitest 5 ([#25])
- Improve the UX for HTML coverage ([#22])
- Stabilize CI OS choices ([#21])
- Reduce duplication in command tests ([#19])
- Add completions for test paths ([#17])
- Formalize the release workflow ([#16])
- Fix Windows verification of published packages ([#15])

## [0.0.3] (2026-09-16)

### Changes

- Make the public version of `ValuesOf` report narrow flag types ([#6])
- Exclude managed commands from explore output by default ([#2])
- Reduce the package size by removing source maps ([#4])

### Development

- Include Windows in CI tests ([#12])
- Improve documentation ([#11])
- Expand and improve publishing tests ([#10])
- Refresh and slim down the agents file ([#9])
- Ensure full test coverage ([#8])
- Add coverage reporting ([#7])
- Improve test infrastructure ([#5])
- Upgrade dependencies ([#3])

## [0.0.2] (2026-09-13)

### Features

- Configure trusted publishing

## [0.0.1] (2026-09-13)

### Features
